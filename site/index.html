Você Descreve.A IA Constrói.

You Describe.The AI Builds.

Isto não é um curso de programação. Você não vai decorar linguagens nem virar desenvolvedor. Vai aprender a usar IAs como o Claude Code e o Cursor — ferramentas que entendem português e escrevem o código por você.

This is not a programming course. You won't memorize languages or become a developer. You'll learn to use AI like Claude Code and Cursor — tools that understand plain language and write the code for you.

Você vira o arquiteto: descreve o que precisa, do jeito que explicaria para um estagiário. A IA vira o operário: monta a ferramenta, cria os arquivos e faz funcionar.

You become the architect: describe what you need, the way you'd explain it to an intern. The AI becomes the builder: assembles the tool, creates the files and makes it work.

O resultado é seu, roda no seu computador e faz exatamente o que você pediu.

The result is yours, runs on your computer and does exactly what you asked for.
