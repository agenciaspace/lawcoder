# Roteiro de Video-Aula — Módulo 05
## Editores de Código com IA
**Duração estimada:** 20-25 minutos
**Público:** Qualquer pessoa da área jurídica
**Tom:** Prático, demonstrando criação ao vivo

---

## ABERTURA (0:00 — 1:30)

### O que mostrar na tela
- Cursor aberto
- Título: "Editores com IA — Seu Novo Ambiente de Criação"

### O que falar
"Neste módulo, você vai aprender a usar editores de código com IA para criar aplicativos. Pense nisso como um Word superpoderoso. Em vez de escrever documentos, você cria programas e sites. E a IA escreve o código enquanto você descreve o que quer em português.

Vamos usar o Cursor como exemplo, mas funciona quase igual no Windsurf e no VS Code com Copilot.""

---

## SEÇÃO 1: Interface (1:30 — 4:00)

### O que mostrar na tela
- Cursor com um projeto aberto
- Apontando cada área da tela

### O que falar
"A interface tem três áreas principais.

À esquerda: o explorador de arquivos. É como as pastas do seu computador. Aqui ficam todos os arquivos do seu projeto.

No centro: o editor. É onde você vê e edita os arquivos. Parece com um editor de texto normal.

À direita ou embaixo: o chat com a IA. É aqui que acontece a mágica. Você descreve o que quer e a IA cria os arquivos.""

---

## SEÇÃO 2: Criando Algo do Zero (4:00 — 12:00)

### O que mostrar na tela
- Cursor com pasta vazia aberta
- Chat aberto
- Prompt sendo digitado
- IA criando arquivos
- Teste no navegador

### O que falar
"Vamos criar algo juntos. Abra uma pasta vazia. No chat, cole este prompt:

'Crie um app web que calcule prazos processuais. O usuário digita a data de intimação, escolhe o prazo em dias — 10, 15 ou 30 — e o app mostra a data final considerando dias úteis. Use HTML, CSS e JavaScript. Design azul escuro, branco e cinza. Responsivo para celular.'

[esperar a IA criar]

Ela criou os arquivos. Vamos testar. Clique com o botão direito no index.html e escolha Open in Browser.

[mostrar o app funcionando]

Funcionou. Agora vamos pedir uma melhoria.

[no chat]
'Adicione um campo para o usuário digitar o número do processo e um botão para exportar o resultado como PDF. Use uma biblioteca CDN para o PDF.'

[esperar]

[testar de novo]

Você acabou de criar um app funcional e pedir melhorias só com descrições em português.""

---

## SEÇÃO 3: Dicas de Comunicação (12:00 — 16:00)

### O que mostrar na tela
- Lista de dicas na tela

### O que falar
"Algumas dicas para obter melhores resultados.

Primeira: seja específico. Quanto mais detalhes, melhor. Em vez de 'deixe bonito', diga 'use azul escuro, fonte Inter, cantos arredondados'.

Segunda: faça por partes. Em vez de pedir um app gigante de uma vez, peça a estrutura básica primeiro, depois adicione funcionalidades.

Terceira: use referências. 'Tipo o app tal' ou 'com a cara do site tal' ajuda muito.

Quarta: peça explicações. 'Explique o que esse arquivo faz' — a IA ensina enquanto cria.

Quinta: não desista no primeiro erro. Cole o erro no chat e peça para corrigir. É normal precisar de duas ou três tentativas.""

---

## SEÇÃO 4: Comparativo Rápido (16:00 — 19:00)

### O que mostrar na tela
- Tabela comparativa simples

### O que falar
"Cursor versus Windsurf versus VS Code com Copilot.

O Cursor é o mais completo. Tem o chat mais inteligente e consegue editar vários arquivos ao mesmo tempo. É o que eu recomendo para criar apps do zero.

O Windsurf é mais simples. O modo agente dele é muito intuitivo. Você aperta Ctrl+I e ele trabalha sozinho. Bom para quem está começando.

O VS Code com Copilot é ideal se você já usa o VS Code. Ele sugere código enquanto você trabalha, como um autocomplete superinteligente.

Escolha um e use. Não precisa dominar os três.""
