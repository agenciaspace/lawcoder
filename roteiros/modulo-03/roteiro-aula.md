# Roteiro de Video-Aula — Módulo 03
## O Terminal É Só Um Chat de Texto
**Duração estimada:** 15-18 minutos
**Público:** Qualquer pessoa da área jurídica, primeiro contato com terminal
**Tom:** Descontraído, desmistificador, mostrando tela

---

## ABERTURA (0:00 — 2:00)

### O que mostrar na tela
- Tela preta de terminal em tamanho grande
- Título animado: "O Terminal Não É Seu Inimigo"

### O que falar
"Se tem uma coisa que assusta quem não é da tecnologia, é essa tela preta aqui. O terminal. A linha de comando.

Mas hoje eu vou te mostrar que o terminal é só um chat de texto com seu computador. É como mandar mensagens para um funcionário muito obediente. Você dá um comando curto, ele executa imediatamente.

Você só precisa saber cinco comandos. Cinco. E é isso que a gente vai ver agora.""

---

## SEÇÃO 1: Abrindo o Terminal (2:00 — 3:30)

### O que mostrar na tela
- Windows: menu iniciar → digitar "terminal" → abrir
- Mac: Cmd+espaço → digitar "terminal" → abrir

### O que falar
"Primeiro, como abrir.

No Windows: aperte a tecla Windows, digite 'terminal' ou 'cmd' e aperte Enter.

No Mac: aperte Cmd+espaço, digite 'terminal' e aperte Enter.

Pronto. Tela preta. Cursor piscando. Parece de filme de hacker, mas é só isso.""

---

## SEÇÃO 2: Os 5 Comandos (3:30 — 10:00)

### O que mostrar na tela
- Terminal em tamanho grande, fonte aumentada
- Cada comando sendo digitado e o resultado aparecendo

### O que falar
"Comando um: pwd. Significa 'print working directory'. Em português: mostra em qual pasta você está. É como olhar o endereço no GPS.

[mostrar pwd sendo digitado e resultado]

Comando dois: ls no Mac, ou dir no Windows. Lista o que tem na pasta. É como abrir uma pasta no computador e ver os arquivos.

[mostrar ls ou dir]

Comando três: cd. Change directory. Entra numa pasta. É como dar dois cliques numa pasta.

[mostrar cd Documentos]

Comando quatro: cd dois pontos. Volta uma pasta. É como clicar em voltar no navegador.

[mostrar cd ..]

Comando cinco: mkdir. Make directory. Cria uma pasta nova. É como clicar com o botão direito e criar nova pasta.

[mostrar mkdir meu-primeiro-projeto]

Só isso. Esses cinco comandos são noventa por cento do que você vai precisar.""

---

## SEÇÃO 3: Prática Guiada (10:00 — 14:00)

### O que mostrar na tela
- Terminal limpo, passo a passo

### O que falar
"Agora a gente faz junto. Abra o terminal e digite exatamente o que eu digitar.

Primeiro: pwd. Veja onde você está.

Segundo: ls ou dir. Veja o que tem aí.

Terceiro: mkdir meu-primeiro-projeto

Quarto: cd meu-primeiro-projeto

Quinto: ls ou dir. Vai estar vazio, porque a pasta é nova.

Sexto: cd .. para voltar.

Parabéns. Você acabou de usar o terminal.""

---

## SEÇÃO 4: Quando Usar Terminal vs Mouse (14:00 — 16:00)

### O que mostrar na tela
- Tabela comparativa simples

### O que falar
"Quando usar o terminal e quando usar o mouse?

Use o mouse normal para navegar, abrir arquivos, organizar documentos. Use o terminal quando uma ferramenta de IA pedir, quando precisar instalar algo rapidamente, ou quando quiser criar várias pastas de uma vez.

A regra é simples: se você está seguindo um tutorial de IA, provavelmente vai precisar do terminal. Fora isso, use o mouse sem culpa.""

---

## FECHAMENTO (16:00 — 18:00)

### O que mostrar na tela
- Recapitulação dos 5 comandos
- Próximo módulo: "Ferramentas de Linha de Comando"

### O que falar
"Recapitulando: pwd mostra onde você está. ls lista arquivos. cd entra na pasta. cd .. volta. mkdir cria pasta.

No próximo módulo, a gente usa o terminal para instalar ferramentas de IA que criam coisas só com comandos de texto. Você vai ver como isso é poderoso.

Até lá.""
