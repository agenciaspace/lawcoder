# Roteiro de Video-Aula — Módulo 06
## Projeto 1: Seu Primeiro App
**Duração estimada:** 30-35 minutos
**Público:** Qualquer pessoa da área jurídica
**Tom:** Mão na massa total, passo a passo junto com o aluno

---

## ABERTURA (0:00 — 2:00)

### O que mostrar na tela
- Cursor aberto com pasta vazia
- Título: "Projeto 1 — App de Cálculo de Prazos Processuais"

### O que falar
"Chegou a hora do primeiro projeto prático. A gente vai criar juntos um aplicativo real: uma calculadora de prazos processuais que considera dias úteis, tem histórico, exporta PDF e funciona no celular.

Vou fazer na minha tela. Você faz na sua. Se algo der errado, pausa e tenta de novo. Vamos lá.""

---

## PASSO 1: Criar a Pasta (2:00 — 3:30)

### O que mostrar na tela
- Terminal ou explorador de arquivos
- Criação da pasta

### O que falar
"Primeiro, crie uma pasta chamada calculadora-prazos na sua área de trabalho ou em documentos. Pode usar o botão direito do mouse ou o terminal com mkdir.""

---

## PASSO 2: Abrir no Editor (3:30 — 4:30)

### O que mostrar na tela
- Cursor → File → Open Folder → selecionar pasta

### O que falar
"Abra o Cursor. Vá em File, Open Folder, e selecione a pasta calculadora-prazos que você acabou de criar.""

---

## PASSO 3: Primeiro Prompt (4:30 — 12:00)

### O que mostrar na tela
- Chat do Cursor aberto
- Prompt sendo colado
- IA criando arquivos em tempo real

### O que falar
"No chat de IA, cole exatamente este prompt. Vou deixar na tela para você copiar.

[mostrar prompt na tela]

'Crie um app web completo em uma única página HTML que calcule prazos processuais em dias úteis. Requisitos: campo para inserir data de intimação, campo para número de dias do prazo, checkbox para considerar ou não o dia do início, botão calcular, resultado mostrando data final em vermelho, feriados nacionais pré-carregados, design limpo profissional com cores sóbrias azul escuro branco e cinza, responsivo para celular. Use HTML CSS e JavaScript em um único arquivo index.html.'

[esperar]

A IA está criando o arquivo. Vamos ver o resultado.""

---

## PASSO 4: Testar (12:00 — 14:00)

### O que mostrar na tela
- Arquivo index.html criado
- Clique direito → Open in Browser
- App funcionando no navegador
- Teste com data e prazo

### O que falar
"Clique com o botão direito no index.html e escolha Open in Browser. Teste com uma data e um prazo. Veja se o cálculo faz sentido.

Se algo estiver errado, não se preocupe. A gente corrige no próximo passo.""

---

## PASSO 5: Melhorias (14:00 — 22:00)

### O que mostrar na tela
- Novo prompt no chat
- IA adicionando funcionalidades
- Teste de cada funcionalidade

### O que falar
"Agora vamos adicionar funcionalidades. No chat, digite:

'Adicione: um histórico local dos últimos 10 cálculos salvos no navegador, um botão exportar PDF que gere PDF com o resultado, um campo para anotar número do processo, uma tabela de feriados do ano, animações suaves ao calcular. Mantenha tudo em um arquivo HTML se possível.'

[esperar]

Teste cada nova funcionalidade. O histórico aparece? O PDF gera? Se algo não funcionar, descreva o problema para a IA.

Por exemplo: 'O PDF está saindo sem formatação. Deixe com cabeçalho escrito Cálculo de Prazo Processual e data atual.'

[corrigir]

Veja como é um diálogo. Você pede, testa, ajusta.""

---

## PASSO 6: Publicar (Opcional) (22:00 — 28:00)

### O que mostrar na tela
- app.netlify.com/drop
- Arrastar pasta
- Link gerado

### O que falar
"Quer que outras pessoas acessem seu app? Vamos publicar gratuitamente.

Acesse app.netlify.com/drop. Arraste a pasta do seu projeto para essa tela. Pronto. Em segundos, você recebe um link.

[mostrar link]

Esse link é seu app na internet. Você pode mandar para colegas, usar no celular, ou até vender como produto.""

---

## FECHAMENTO (28:00 — 35:00)

### O que mostrar na tela
- App finalizado funcionando
- Recapitulação dos passos

### O que falar
"Você acabou de criar um app funcional, útil no dia a dia jurídico, sem escrever código. O app é seu. Pode usar no escritório, compartilhar, ou vender.

No próximo módulo, a gente sobe o nível. Vamos criar um assistente automático que trabalha sozinho. Te vemos lá.""
