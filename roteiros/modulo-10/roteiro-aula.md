# Roteiro de Video-Aula — Módulo 10
## Segurança, Sigilo e LGPD
**Duração estimada:** 20-25 minutos
**Público:** Qualquer pessoa da área jurídica
**Tom:** Sério, mas não alarmista. Prático.

---

## ABERTURA (0:00 — 2:00)

### O que mostrar na tela
- Título: "Segurança e Sigilo — O Módulo Obrigatório"
- Ícone de cadeado

### O que falar
"Você aprendeu a criar apps, assistentes e automações. Agora precisa aprender a fazer isso de forma segura. Na área jurídica, temos uma responsabilidade extra: proteger dados de clientes. Este módulo é curto, mas essencial. Não pule.""

---

## SEÇÃO 1: O Que Nunca Enviar (2:00 — 5:00)

### O que mostrar na tela
- Lista com ícones de proibido

### O que falar
"Ferramentas como ChatGPT, Claude online e outras processam seus dados nos servidores das empresas. Nunca envie:

Nomes completos de clientes.
CPF, CNPJ ou documentos de identificação.
Números de processos reais.
Endereços, telefones e e-mails de partes.
Fatos íntimos ou sensíveis do caso.
Documentos com segredo de justiça.
Estratégias processuais detalhadas.

Por quê? Porque esses dados podem ser armazenados, processados ou, em caso de vazamento, expostos. E na nossa área, isso é gravíssimo.""

---

## SEÇÃO 2: Riscos Jurídicos (5:00 — 7:30)

### O que mostrar na tela
- Citações de artigos (simplificadas)

### O que falar
"Vazar dados de um cliente pode configurar violação do sigilo profissional, artigo 154 do Código Penal. Além disso, infringe a LGPD, com multas de até dois por cento do faturamento.

Isso não é para te assustar. É para você saber que existe regra, e que seguir as regras é simples.""

---

## SEÇÃO 3: Como Usar de Forma Segura (7:30 — 15:00)

### O que mostrar na tela
- Passo a passo visual

### O que falar
"Cinco práticas simples para usar IA de forma segura.

Primeira: anonimize antes de enviar. Substitua nomes reais por fictícios. Troque João Silva por Parte A. Troque números de processo por zeros. Troque CPF por XXX.

Segunda: use dados fictícios para criar. Quando estiver criando um app, use dados de exemplo. A lógica funciona igual. Depois, use o app localmente com dados reais — aí não sai do seu computador.

Terceira: prefira ferramentas locais. Os apps que você criou e roda no navegador não enviam dados para lugar nenhum. Eles funcionam cem por cento no seu computador. Isso é seguro.

Quarta: desative o treinamento. No ChatGPT, Claude e outras, vá em Configurações, Data Controls, e desative Improve the model. Isso impede que seus dados sejam usados para treinar a IA.

Quinta: use contas empresariais quando disponível. Planos pagos geralmente prometem não usar dados para treinamento. Leia os termos.""

---

## SEÇÃO 4: Alternativas Locais (15:00 — 18:00)

### O que mostrar na tela
- Ollama sendo instalado
- Exemplo de uso local

### O que falar
"Se você precisa processar dados sensíveis, existem alternativas locais.

O Ollama roda modelos de IA no seu computador, sem internet. É ideal para análise de documentos confidenciais.

Seus apps locais, criados no curso, são seguros porque não enviam nada para fora.

O Claude Desktop tem funções que funcionam offline para tarefas que não envolvem dados sensíveis.""

---

## SEÇÃO 5: Checklist e Regra de Ouro (18:00 — 21:00)

### O que mostrar na tela
- Checklist na tela

### O que falar
"Regra de ouro: trate dados de clientes na IA como você trataria uma conversa em elevador. Não fale o que não contaria para um estranho.

Checklist para cada projeto:
Os dados usados nos testes são fictícios?
O app funciona localmente?
Se publicar na internet, há senha?
Desativei o treinamento de modelo?
Em caso de dúvida, consultei a OAB ou compliance?""

---

## SEÇÃO 6: LGPD na Prática (21:00 — 23:00)

### O que mostrar na tela
- Quatro princípios simples

### O que falar
"Se você criar um app para uso interno ou para vender, lembre-se da LGPD.

Mínimo necessário: colete apenas os dados essenciais.
Consentimento: informe como os dados são usados.
Segurança: use senhas e controle de acesso.
Exclusão: permita que usuários peçam para apagar dados.""
